<h3 align="center">💻 How to Run These Projects</h3>

<details>
<summary><b>🔥 Run: Real-Time Forum (Go + JS)</b></summary>
<br>
Backend (Go):
<pre>
git clone https://github.com/jbajady/real-time-forum.git
cd real-time-forum
go run ./cmd/server
# Backend listens on :8080
</pre>
Frontend:
<pre>
cd frontend
npm install
npm run dev
</pre>
</details>

<details>
<summary><b>🦀 Run: 0-shell (Rust)</b></summary>
<br>
<pre>
git clone https://github.com/bdaanoun/0-shell.git
cd 0-shell

# Build
cargo build --release

# Run
cargo run -- &lt;args&gt;
</pre>
</details>
